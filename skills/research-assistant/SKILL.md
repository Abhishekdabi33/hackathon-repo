# Research Assistant Skill

## Purpose
Enables the agent to process complex developer documentation, extract key API endpoints, summarize architectural concepts, and generate implementation tutorials.

## When to Use
- When summarizing open-weight model documentation (Gemma, Hermes, Llama).
- When preparing developer quickstarts or pitch deck technical appendices.

## Operational Instructions
1. **Document Parsing**:
   - Extract primary concepts, prerequisites, and code snippets.
2. **Key Findings Synthesis**:
   - Highlight trade-offs (latency vs accuracy, memory footprint, hosting cost).
3. **Actionable Delivery**:
   - Output structured cheat-sheets with copy-pasteable terminal commands.
